# 各 App 轨迹导出操作指南

> 本工具**不提供**百度/高德/腾讯/Google 等第三方 App 的账号扫码登录，也不做逆向抓取。  
> 请先在你常用的 App 里把轨迹导出为 **GPX / KML / KMZ / JSON / CSV / TCX / FIT** 等文件，再上传到本工具。
>
> App 菜单会随版本变化，以下路径以常见版本为例；如果找不到，请先在 App 内搜索「导出」「分享」「下载」「轨迹文件」「个人信息副本」，或以 App 当前界面为准。

## 三步流程

1. **导出**：按下方对应 App 的步骤，把轨迹导出为 GPX/KML/JSON/CSV 等文件。
2. **上传**：打开本工具的「同步」页，手机扫二维码上传；或把文件放进 NAS 的 `data/inbox/` 文件夹。
3. **入库**：上传会自动解析入库；文件夹方式在「同步」页点「扫描并入库」。之后到「地图总览」/「里程碑」查看。

## 地图导航类 App（官方通常不提供轨迹文件导出）

> 截至本指南编写时，百度地图、高德地图、腾讯地图的官方 App 面向普通用户主要提供「足迹/历史行程查看、分享、生成图片」，**没有稳定的 GPX/KML 轨迹文件导出入口**（如后续版本新增，以 App 内为准）。  
> 可通过以下方式处理：

### 百度地图

1. 打开百度地图 → 我的 → 足迹/行程，确认是否有「导出」「下载」入口（多数版本没有）。
2. 若没有：通过百度地图 App「我的 → 客服/帮助与反馈」或百度隐私保护平台提交**个人信息副本申请**，说明需要导出本人账号下的位置/轨迹数据。
3. 百度地图开放平台（开发者）的鹰眼轨迹服务可导出接入应用的轨迹 JSON，但这只适用于你自己接入的数据，不是普通用户足迹。
4. 如果只是想要可导入的轨迹文件，建议以后使用下方支持导出的运动/户外 App 记录。

### 高德地图

1. 高德地图 → 我的 → 足迹，查看是否有导出入口；多数版本只能查看和分享图片。
2. 通过高德地图 App 的「设置 → 帮助与客服」提交个人信息副本申请（账号、时间范围、数据内容：轨迹/位置记录）。
3. 高德开放平台的猎鹰轨迹/路径规划接口面向开发者，不能直接导出个人足迹。

### 腾讯地图

1. 腾讯地图 → 我的 → 足迹，确认是否有导出入口；多数版本没有。
2. 通过腾讯地图客服或腾讯隐私保护平台提交个人信息副本申请。
3. 腾讯地图的路线分享链接不是轨迹文件，不能直接导入本工具。

#### 个人信息副本申请模板（可直接改后发给客服）

```text
主题：申请导出本人账号下的个人信息副本（位置/轨迹数据）

账号：<注册手机号或账号>
时间范围：<例如 2023-01-01 至今>
数据内容：本人使用该 App 产生的轨迹/位置记录（经纬度、时间、海拔等）
文件格式：GPX / KML / JSON / CSV 均可
用途：个人数据备份与导入本人 NAS 的轨迹管理工具
依据：《中华人民共和国个人信息保护法》第四十五条（查阅、复制个人信息）
联系方式：<手机号/邮箱>

请告知是否需要补充身份验证材料，谢谢。
```

## 运动 / 户外 App（多数支持官方导出）

### 华为运动健康（GPX / 路线文件）

1. 打开华为运动健康 App → 运动页，点击「累计跑步 / 累计骑行 / 累计步行」。
2. 选择一条有轨迹的户外运动记录，进入轨迹页面。
3. 点击右侧「路线」图标 → 「导出路线文件」→ 确定 → 选择保存/分享方式，保存到手机或 NAS。
4. 仅户外跑步、户外骑行、户外步行支持；导出的路线文件可直接上传本工具（若为 GPX 可直接识别）。

官方说明：<https://consumer.huawei.com/cn/support/content/zh-cn15893332/>

### Garmin Connect（GPX / TCX / FIT）

1. 打开 Garmin Connect 网页或 App → 活动记录。
2. 进入某条活动 → 右上角菜单「…」→「导出」。
3. 选择 GPX（轨迹）、TCX（含训练数据）或 FIT（原始文件）；本工具三种都支持。
4. 批量导出可在 Garmin Connect 网页版账户设置中查找「导出数据」。

### Strava（GPX / TCX / FIT）

1. 打开 Strava 网页版 → 进入某条活动。
2. 点击「更多/…」→「导出 GPX」或「导出原始文件」。
3. 也可在活动地址后加 `/export_tcx` 下载 TCX。
4. 批量导出：Settings → My Account → Download your account。

官方说明：<https://support.strava.com/hc/en-us/articles/216918437-Exporting-your-Data-and-Bulk-Export>

### 两步路

1. 打开两步路 App → 我的 → 轨迹。
2. 选择目标轨迹，进入轨迹详情页，找「分享 / 更多 / 导出」。
3. 选择导出 GPX 或 KML，保存到手机文件。
4. 若只有「分享到社区/我的轨迹」，可先在 App 内查看轨迹详情是否有下载按钮；不同版本入口略有差异。

### 六只脚

1. 打开六只脚 App → 我的 → 轨迹。
2. 进入轨迹详情，找「导出 / 下载 / 分享轨迹文件」。
3. 常见导出格式为 KML 或 GPX，保存到手机后上传。

### 行者

1. 打开行者 App → 运动记录或路书详情。
2. 选择目标记录 → 分享/更多 → 导出 GPX（部分版本在「路书」页面提供 GPX 下载）。
3. 若只有路书导出，可把路书文件当作轨迹导入；注意路书不一定包含你的实际运动时间。

参考：<https://hc.imxingzhe.com/hc/xing/articles/1702280960-gpx-gpx>

### 奥维互动地图

1. 打开奥维互动地图 → 收藏/轨迹。
2. 选择目标轨迹或对象 → 导出 → KML/GPX（不同版本入口不同）。
3. 导出 KML 后可上传本工具；若坐标是百度/高德偏移坐标，导入时在文件卡片切换对应坐标系。

### Apple 健康（Apple Watch 路线 GPX）

1. iPhone 打开「健康」App → 右上角头像。
2. 滑到底部 →「导出所有健康数据」→ 导出。
3. 得到 `export.zip`，解压后进入 `workout-routes/` 文件夹；里面有带 GPS 的运动路线 `.gpx` 文件。
4. 把这些 GPX 上传本工具即可（没有路线的运动不会生成 GPX）。

### Google 地图 / 时间线（Location History JSON）

1. 打开 <https://takeout.google.com/>，登录 Google 账号。
2. 点「取消全选」，只勾选「位置记录 / Location History」。
3. 创建导出，等待邮件/页面提供下载；导出包内常见为 `Records.json` 或 `Semantic Location History/年/年_月.json`。
4. 把 JSON 直接上传本工具，会自动识别为「Google 时间线」。
5. 注意：2024 年起 Google 逐步把时间线迁移到设备端，部分账号的 Takeout 导出可能不再包含最新时间线；如导出包中没有位置记录，请在 Google 地图 App 内查看时间线，具体导出方式以 Google 当前帮助为准。

### 其他运动 App（Keep / 悦跑圈 / 咕咚 / Nike Run Club 等）

- 这些 App 通常没有公开的 GPX/KML 导出入口。
- 可在 App 的「设置 → 隐私 → 个人信息副本/下载我的数据」中查找；没有的话联系客服按上面的模板申请。
- 如果只是想把今后的轨迹汇总到本工具，建议改用支持导出的 App（华为运动健康、Garmin、Strava、两步路、六只脚、行者等）。

## 通用转换工具

- 如果导出的是其他格式（如 KML、CSV、FIT、TCX），可直接尝试上传，本工具会自动识别。
- 遇到不支持的格式，可在电脑上使用 **GPSBabel**（<https://www.gpsbabel.org/>）转换为 GPX 后再上传。
- 注意：截图、录屏、路线分享链接**不是轨迹文件**，无法还原为完整轨迹。

## 上传到本工具

- **手机扫码**：电脑打开「同步」页 → 生成二维码 → 手机同局域网扫码 → 选择文件上传。
- **NAS 同步文件夹**：把文件放进 `data/inbox/`（飞牛部署路径：`/vol1/1000/docker/maptrack-merger/data/inbox/`）→ 在「同步」页点「扫描并入库」。
- **直接导入**：在「导入合并」页拖拽文件，解析后可保存到轨迹库。

> 所有文件只在本机 / NAS 上解析，不会上传到任何第三方服务。
