合规说明

百度地图、高德地图、腾讯地图、Google 地图等第三方 App 没有公开的个人轨迹同步接口，本工具不提供、也不会实现账号扫码登录或逆向抓取。

请使用以下替代流程：

  1. 在手机 App 里导出轨迹为 GPX / KML / JSON / CSV 等文件；
  2. 扫描左侧二维码打开手机上传页，选择文件上传；或把文件放进 NAS 的 data/inbox/；
  3. 回到本页点击「扫描并入库」（或上传页自动入库），轨迹会出现在「地图总览」。
