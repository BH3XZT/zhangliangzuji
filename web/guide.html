轨迹导出操作指南

把散落在各个 App 里的轨迹先导出成文件，再汇总到 NAS 的一张地图上。

GPX · KML · KMZ · TCX · GeoJSON · JSON · CSV · FIT
本工具不提供第三方 App 的账号扫码登录。 百度/高德/腾讯/Google 等官方 App 没有公开的个人轨迹同步接口，逆向登录会有账号风险。请在原 App 内导出轨迹文件（或用下方申请模板向客服申请个人信息副本），再通过「同步」页二维码上传，或放进 NAS 的 data/inbox/ 文件夹扫描入库。

1在原 App 导出

按下面各 App 的步骤，把轨迹导出为 GPX/KML/JSON/CSV 等文件。

2传到 NAS

手机扫「同步」页二维码上传，或把文件放进 data/inbox/。

3自动入库

上传自动解析；文件夹方式点「扫描并入库」。之后到地图总览/里程碑查看。

百度地图官方无直接导出需申请数据副本查看步骤 ▾

截至本指南编写时，百度地图 App 的「足迹/行程」面向普通用户主要是查看和分享，没有稳定的 GPX/KML 轨迹文件导出入口（如果新版本新增入口，以 App 内为准）。

  1. 先在「我的 → 足迹/行程」里找「导出 / 下载 / 分享文件」；多数版本只有生成图片。
  2. 找不到时，通过 App「我的 → 客服/帮助与反馈」提交个人信息副本申请（见页面下方模板）。
  3. 开发者接入百度鹰眼轨迹服务的数据可在开放平台导出 JSON，但那只适用于你自己接入的数据，不是普通用户足迹。
  4. 如果只是想把轨迹汇总，建议今后使用下方支持导出的运动/户外 App 记录。

百度地图开放平台：lbsyun.baidu.com（面向开发者，不是普通用户足迹导出）

高德地图官方无直接导出需申请数据副本查看步骤 ▾

高德地图 App 的「足迹」通常只能查看/分享图片，没有面向普通用户的轨迹文件导出入口（以当前版本为准）。

  1. 打开「我的 → 足迹」确认是否有导出/下载按钮。
  2. 没有的话，通过「设置 → 帮助与客服」提交个人信息副本申请（账号、时间范围、位置/轨迹数据）。
  3. 高德开放平台的猎鹰轨迹接口面向开发者，不能直接导出个人足迹。

高德开放平台：lbs.amap.com

腾讯地图官方无直接导出需申请数据副本查看步骤 ▾

腾讯地图的足迹/历史行程通常只能查看，路线分享链接不是轨迹文件，不能直接导入。

  1. 在 App 内查看是否存在「导出/下载」入口。
  2. 没有的话，通过腾讯地图客服或腾讯隐私保护平台提交个人信息副本申请。
  3. 建议今后使用支持 GPX 导出的运动/户外 App 记录。
华为运动健康官方支持导出GPX / 路线文件查看步骤 ▾
  1. 打开华为运动健康 App → 运动页，点击「累计跑步 / 累计骑行 / 累计步行」。
  2. 选择一条有轨迹的户外运动记录，进入轨迹页面。
  3. 点击右侧「路线」图标 →「导出路线文件」→ 确定 → 选择保存/分享方式。

仅户外跑步、户外骑行、户外步行支持；HarmonyOS 5 及以上路径略有不同。

Garmin Connect官方支持导出GPX / TCX / FIT查看步骤 ▾
  1. 打开 Garmin Connect 网页或 App → 活动记录。
  2. 进入某条活动 → 右上角「…」→「导出」。
  3. 选择 GPX（轨迹）、TCX（含训练数据）或 FIT（原始文件），本工具三种都支持。
  4. 批量导出可在网页版账户设置里查找「导出数据」。

Strava官方支持导出GPX / TCX / FIT查看步骤 ▾
  1. 打开 Strava 网页版 → 进入某条活动。
  2. 「更多 / …」→「导出 GPX」或「导出原始文件」。
  3. 也可在活动地址后加 /export_tcx 下载 TCX。
  4. 批量导出：Settings → My Account → Download your account。

仅 GPS 活动能导出有效 GPX；室内活动可能为空文件。

两步路支持导出GPX / KML查看步骤 ▾
  1. 打开两步路 App → 我的 → 轨迹。
  2. 选择目标轨迹，进入轨迹详情页，找「分享 / 更多 / 导出」。
  3. 选择导出 GPX 或 KML，保存到手机文件。

不同版本入口略有差异；若只有分享图片，先在 App 内搜索「导出轨迹」或更新到最新版。

六只脚支持导出KML / GPX查看步骤 ▾
  1. 打开六只脚 App → 我的 → 轨迹。
  2. 进入轨迹详情，找「导出 / 下载 / 分享轨迹文件」。
  3. 常见导出格式为 KML 或 GPX，保存到手机后上传。

六只脚官网 ↗

行者支持导出GPX查看步骤 ▾
  1. 打开行者 App → 运动记录或路书详情。
  2. 选择目标记录 → 分享/更多 → 导出 GPX（部分版本在路书页面提供 GPX 下载）。

路书导出不一定包含你的实际运动时间；运动记录导出才含完整时间轴。

行者 GPX 说明 ↗

奥维互动地图支持导出KML / GPX查看步骤 ▾
  1. 打开奥维互动地图 → 收藏/轨迹。
  2. 选择目标轨迹或对象 → 导出 → KML/GPX（不同版本入口不同）。
  3. 若导出坐标是百度/高德偏移坐标，导入时在文件卡片切换对应坐标系。
Apple 健康（iPhone / Apple Watch）支持导出GPX（workout-routes）查看步骤 ▾
  1. iPhone 打开「健康」App → 右上角头像。
  2. 滑到底部 →「导出所有健康数据」→ 导出。
  3. 解压 export.zip，进入 workout-routes/ 文件夹，里面有带 GPS 的运动路线 .gpx 文件。
  4. 上传这些 GPX 即可。

没有 GPS 路线的运动不会生成 GPX；导出包较大时建议在电脑上解压。

Google 地图 / 时间线官方支持导出JSON（Takeout）查看步骤 ▾
  1. 打开 takeout.google.com 并登录 Google 账号。
  2. 点「取消全选」，只勾选「位置记录 / Location History」。
  3. 创建导出并下载；包内常见为 Records.json 或 Semantic Location History/年/年_月.json。
  4. 把 JSON 直接上传本工具，会自动识别为「Google 时间线」。

2024 年起 Google 逐步把时间线迁移到设备端，部分账号的 Takeout 可能不再包含最新时间线；如导出包没有位置记录，以 Google 地图当前帮助为准。

Keep / 悦跑圈 / 咕咚 / Nike Run Club 等通常无官方导出需申请数据副本查看步骤 ▾

这些运动 App 通常没有公开的 GPX/KML 导出入口：

  1. 先找「设置 → 隐私 → 个人信息副本 / 下载我的数据」。
  2. 没有的话，按下方模板联系客服申请。
  3. 今后可改用华为运动健康、Garmin、Strava、两步路、六只脚、行者等支持导出的 App。
通用转换工具 GPSBabel格式转换任意 → GPX查看步骤 ▾
  1. 如果导出的是 KML/CSV/FIT/TCX，先直接尝试上传，本工具大多能自动识别。
  2. 遇到不支持的格式，可在电脑安装 GPSBabel，把它转换为 GPX 后再上传。
  3. 截图、录屏、路线分享链接不是轨迹文件，无法还原成完整轨迹。

个人信息副本申请模板

百度/高德/腾讯等 App 若没有导出入口，可用下面模板发给客服，按《个人信息保护法》第四十五条申请复制本人个人信息。

主题：申请导出本人账号下的个人信息副本（位置/轨迹数据）

账号：<注册手机号或账号>
时间范围：<例如 2023-01-01 至今>
数据内容：本人使用该 App 产生的轨迹/位置记录（经纬度、时间、海拔等）
文件格式：GPX / KML / JSON / CSV 均可
用途：个人数据备份与导入本人 NAS 的轨迹管理工具
依据：《中华人民共和国个人信息保护法》第四十五条（查阅、复制个人信息）
联系方式：<手机号/邮箱>

请告知是否需要补充身份验证材料，谢谢。
① 扫码上传电脑打开「同步」页生成二维码，手机扫码选择轨迹文件。 ② NAS 同步文件夹把文件放进 data/inbox/，在「同步」页点「扫描并入库」。 ③ 直接导入在「导入合并」页拖拽文件，解析后可保存到轨迹库。

支持格式：GPX / KML / KMZ / TCX / GeoJSON / 通用 JSON / 百度地图 JSON / 高德地图 JSON / Google 时间线 / CSV / TSV / NMEA / FIT。
App 菜单可能随版本更新变化；以上路径仅供参考，以各 App 当前版本为准。所有文件只在本机 / NAS 上解析，不上传到任何第三方服务。
